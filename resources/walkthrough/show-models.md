# Choose a model in Copilot Chat

After **Unified Proxy: Reload Config**, every key under `proxies` in your config appears as a separate model under the **Unified Proxy** vendor.

Open Copilot Chat, click the model picker, and select the entry you configured (e.g. **my-model**).

- Hover the model to change **thinking effort** (Off / Standard / Deep) — same UI as DeepSeek V4.
- If a model is missing, run **Reload Config** again or restart VS Code.

[Open Language Models manager](command:workbench.action.chat.manage) if entries are hidden.
