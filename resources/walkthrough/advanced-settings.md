# Advanced settings

Optional VS Code settings (prefix `unified-proxy-copilot.`):

- **proxyConfigPath** — custom path to `proxy_configs.json`
- **debugMode** — `minimal` / `metadata` / `verbose` (see DeepSeek V4 v0.7.1)
- **experimental.stabilizeToolList** — tool-list stability (see DeepSeek V4 v0.7.1)

[Open extension settings](command:unified-proxy-copilot.openSettings) · [Show Logs](command:unified-proxy-copilot.showLogs)

For vision proxy, request dumps, and tool-drift notices, refer to **DeepSeek V4 for Copilot Chat v0.7.1** documentation.
