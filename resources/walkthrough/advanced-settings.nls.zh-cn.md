# 高级设置

可选 VS Code 设置（前缀 `unified-proxy-copilot.`）：

- **proxyConfigPath** — 自定义 `proxy_configs.json` 路径
- **debugMode** — `minimal` / `metadata` / `verbose`（说明见 DeepSeek V4 v0.7.1）
- **experimental.stabilizeToolList** — 稳定工具列表（说明见 DeepSeek V4 v0.7.1）

[打开插件设置](command:unified-proxy-copilot.openSettings) · [显示日志](command:unified-proxy-copilot.showLogs)

视觉代理、请求 dump、工具漂移说明等通用能力，请参阅 **DeepSeek V4 for Copilot Chat v0.7.1** 官方文档。
