# 在 Copilot Chat 中选择模型

执行 **Unified Proxy: Reload Config** 后，`proxy_configs.json` 里 `proxies` 的每个键都会在 **Unified Proxy** 提供商下显示为一个独立模型。

打开 Copilot Chat，点击模型选择器，选择你配置的条目（例如 **my-model**）。

- 鼠标悬停可切换 **思考模式**（停用 / 标准 / 深度），与 DeepSeek V4 原版一致。
- 若看不到新模型，请再次 **Reload Config** 或 Reload Window。

若条目被隐藏，可 [打开语言模型管理](command:workbench.action.chat.manage)。
